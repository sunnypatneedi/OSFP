# OSFP verification-evidence predicate, v0.1

This page names the predicate type of OSFP verification evidence:

`https://github.com/sunnypatneedi/OSFP/blob/main/predicates/verification-evidence/v0.1.md`

An in-toto Statement with this `predicateType` carries an OSFP verification-evidence record as its predicate. Section 9 of [the standard](../../spec/STANDARD.md) defines the record and its rules. This page defines nothing on its own.

A breaking change to the evidence record gets a new version, and a new page beside this one.
