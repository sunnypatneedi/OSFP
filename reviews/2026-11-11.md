# Review 1 — 2026-11-11

**Reviewer:** a fresh-context AI reviewer. Not an outside reader (GOVERNANCE.md).
**Text reviewed:** an unpublished earlier draft of 0.1.0-draft.1. Its rule IDs differ from this draft's, so the findings below are stated by topic.
**Verdict:** block, with 22 findings. Each is addressed in the published draft.

| # | Finding | Fix |
|---|---|---|
| 1 | The name collides with a hardware specification, and the `dev.osfp` event types sat on a domain the maintainer does not hold | The event types use the maintainer's GitHub namespace, and the predicate type page lives in this repository. The owner checked the collision and kept the name |
| 2 | No license | The owner chose the Apache License 2.0 |
| 3 | Conformance classes and levels did not fit the rules | Levels are gone. Each class lists its rules, and each rule names its classes in `standard.json` |
| 4 | A build or a linter could never pass, and pytest exits 0 when every test is skipped | Checks count examined units, and a skipped unit is not examined |
| 5 | The checker did not tie a rule's text to its ID | Each rule's text is compared with its own definition. Review 2 found that the comparison tested containment; it now tests equality |
| 6 | The rule on unknown attempts cited a source that makes retries safe, and "retry" was undefined | Retry and re-send are defined. No new attempt starts while one is `unknown` without a person's decision, which review 2 made a recorded grant |
| 7 | The unknown-fields rule cited RFC 9413, and RFC 9396 rejects unknown fields | The rule cites A2A. A grant is its own record, not an `authorization_details` carrier |
| 8 | The A2A mapping was one state off, and `TASK_STATE_UNSPECIFIED` is a zero value | A two-way mapping, set by which side is the A2A server. Review 2 changed how `unknown` travels |
| 9 | The MCP tool rule could not be met: MCP has no tool digest, plugins are not tools, and harnesses have built-in tools | MCP tools are named by server and tool. Built-in tools are limited through restrictions. Tool digests moved to the parking lot |
| 10 | Weak citations for the authority rules, the stop rule, the alert rule, and the enforcement rule | Saltzer and Schroeder, the confused deputy, and MCP support the authority rules. The stop rule cites only the stop. The alert rule was narrowed, and later cut as a product decision |
| 11 | `approvedBy` need not be a person, and scheduled tasks sat outside the grant rules | `approvedBy` names a person. Derived grants stay within their standing grant, and scheduled tasks run under grants |
| 12 | The side-effect rule had no reference point, and harnesses make most side effects | The factory confirms the task's latest grant. Side effects the factory cannot see are stated as out of its reach, and restrictions on them are labeled `instruction` |
| 13 | The credential rule let a credential sit in an environment variable | One rule covers model input. A SHOULD covers code the model writes, and states why it is not yet a MUST |
| 14 | No update model, and the stop fields conflicted with it | Records never change, and outcomes carry a `sequence` |
| 15 | One tree digest for all checks, a `sha256` of a tree, and only one of METR's three methods | Each check carries its own tree digests, as `gitTree` or `dirHash`. Cut-off output is `incomplete`. Reachable answers are recorded, and consumers are bound |
| 16 | The examples used undefined fields, and `not-run` and `died` had no field | The field tables cover every field, and a script enforces them. Overdue results sit on the `overdue` event |
| 17 | "Both implement this profile" and "every factory gets the same things wrong" | Restated as planned and untested; the second claim is cut |
| 18 | DeepSeek was listed as an implementer | Removed. Its source is labeled a machine translation that describes ideas |
| 19 | The maintainer's approval conflicted with the conflict-of-interest rule | The exception is stated. Review 2 narrowed it to drafts |
| 20 | Smaller mismatches: "drafting team", "promised", a wrong section number, "every push", "validated by the schema" | Each corrected |
| 21 | A private tool was named, the checker printed absolute paths, and the predicate type URI did not resolve | The name is gone, the checker prints relative paths only, and the predicate page ships here |
| 22 | Terminology: context, `not_run`, `requested`, run | Disclosure and model input are defined. `not-run` is the only spelling, `requested` is gone, and "attempt" and "scheduled task" replace "run" |
