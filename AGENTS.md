# AGENTS.md

Instructions for AI agents working in this repository. This file is committed on purpose. The rules that bind agents bind every contributor, so they live in [EDITING.md](EDITING.md), in the open.

- Read EDITING.md and GOVERNANCE.md before any edit.
- You may draft, format, cross-check, and propose. The owner decides scope, IDs, names, licenses, governance, and releases.
- Never invent a citation, an adopter, a reviewer, or a governance body.
- Change `spec/STANDARD.md` and `spec/standard.json` in the same commit. Run `node scripts/check-standard.mjs` and `node scripts/check-examples.mjs`, and quote their summary lines.
- After any batch edit, re-read the committed files before you report success.
- Do not push, tag, merge, or open a pull request unless the owner asks. Never merge with a failing check.
